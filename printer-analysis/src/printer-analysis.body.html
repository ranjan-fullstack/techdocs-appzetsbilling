How AppZetBilling prints today (web and Flutter app), which printers fit each subscription plan, and which printer to use for KOT. Evidence tags: [[V]] read in the code or database this session · [[TP]] third-party listing or article · [[EST]] estimate · [[INF]] inference · [[UNK]] not verified · [[REC]] recommendation. Prices come from IndiaMART/Flipkart-type listings and vary by seller.

Summary
  • Basic (₹3,999/yr): 58 mm Bluetooth printer for the phone app (≈ ₹2,500–5,000). No KOT in this plan.
  • Standard (₹5,999/yr): 80 mm USB thermal at the counter (Xprinter XP-80C class) and one at the kitchen PC.
  • Premium (₹9,999/yr): Epson TM-T82 series or TVS RP 3160 Gold at counter and kitchen.
  • KOT: same kind of 80 mm thermal printer on a separate kitchen PC that runs the kitchen login. The phone app cannot print to a kitchen printer.
  • Fix the marketing line "All Type of Printer Support" — it is not accurate.

A ₹3,999 customer will not buy a ₹10,000 printer, so on Basic the honest promise is "bring any 58 mm Bluetooth printer". Premium customers can pay for Epson or TVS.

5. Mobile app and web counter

  • Mobile (Flutter): 58 mm Bluetooth printer, Image printing method for Odia, bills only. Pair it in the phone's Bluetooth settings first, then select it in the app.
  • Web counter: Xprinter XP-80C, TVS RP 3160 Gold or Epson TM-T82 series on a USB port with the vendor driver installed.

6. KOT — which printer

The kitchen role has its own ticket page (kitchen/kots/ticket.blade.php) that prints when it loads [[V]]. So the design is: a kitchen PC or tablet logged in as the kitchen user, with a printer attached to that PC.

RankPrinterWhyWatch out
Best valueXprinter XP-80C, 80 mm USBFast, cutter, KOT is short text so cheap thermal is fine. Fits Standard.Test driver and cutter; India price unknown
Most reliableEpson TM-T82 seriesBest driver and support for all-day use. Fits Premium.Higher price
AlternativeTVS RP 3160 GoldIndian brand with service networkCheck model variant (USB/Serial/Ethernet)
Only for heat, steam or greaseTVS RP 45 Shoppe dot matrixRibbon printing does not fadeNoisy, slow; app compatibility unverified
  • Use the same model at counter and kitchen where possible: one driver and one CSS layout.
  • A cutter is required. 58 mm also works for KOT if money is tight; 80 mm has more room for item names.
  • Fading thermal paper does not matter for a KOT that is used within minutes.
  • The phone app cannot print to a kitchen printer because it holds one Bluetooth connection shared with bills [[V]].

7. Web set-up steps (80 mm)

CSS — add to public/assets/css/business-custom.css (not applied yet):

@media print {
  @page { size: 80mm auto; margin: 0; }
  html, body { width: 80mm; margin: 0; }
  .invoice-container-sm { padding: 0 !important; min-height: 0 !important; }
  .invoice-content-size { max-width: 72mm; margin: 0 auto; }
  .ph-invoice-table th, .ph-invoice-table td { font-size: 10px; padding: 3px 1px; white-space: normal; }
}
  1. Install the vendor's Windows driver. Set paper to the 80 mm roll and enable auto-cut.
  2. Set the printer as the Windows default; turn off "Let Windows manage my default printer".
  3. Allow popups for the site in Chrome or Edge.
  4. Print dialog: Margins None, Scale 100%, Headers and footers off, Background graphics off, paper = 80 mm roll.
  5. Optional silent printing: start Chrome from a shortcut with --kiosk-printing (close all Chrome windows first) — counter and kitchen PCs only.

9. Test protocol for each printer

  1. Print a sale invoice and a KOT from web and from the app.
  2. Use a long item name, a modifier list and an Odia item name.
  3. Check nothing is cut off, no blank paper is fed, and the cutter fires.
  4. Print 20 bills in a row and confirm no missed prints.
  5. Repeat with the app in Image mode for the Odia bill.

Tier A: Epson TM-T82, TVS RP 3160 Gold, Xprinter XP-80C. Tier B: Xprinter XP-58IIH-BT. Everything else: untested until it passes the protocol.
