2. What is already in good shape VERIFIED

  • APP_DEBUG=false, debug/dev packages (debugbar, ignition) are not installed in production vendor.
  • Redis bound to localhost with protected mode; MySQL not listening on the network; ufw, fail2ban and the Monarx malware agent are running.
  • Session cookie is HttpOnly + SameSite=Lax; CSRF cookie is Secure; X-Frame-Options, X-Content-Type-Options, Referrer-Policy are present. CSRF exception list is empty.
  • User passwords use Hash::make (Laravel default driver; the hashing config offers bcrypt/argon, default bcrypt INFERENCE).
  • Daily DB backup with 7-day retention plus an offsite copy exists.
