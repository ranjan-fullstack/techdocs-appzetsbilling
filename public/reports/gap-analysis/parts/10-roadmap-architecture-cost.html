ComponentDecisionReason
Integration serviceIn-process module now; extractable laterTeam and traffic size do not justify microservices; a clean adapter boundary keeps extraction possible
API gatewayNot a separate product yet; nginx + named Laravel rate limiters + API-key middlewareA gateway product adds ops load with no present benefit
Event bus / KafkaNot needed. Use Laravel events + Redis queues (Horizon)Volumes are small (77 sales rows today); Kafka would be pure overhead
Queue / retry / DLQRequired: Redis queue, exponential backoff, failed_jobs + integration dead-letter with replayCurrent queue is the empty DB driver with no worker
Webhook serviceRequired (inbound verified + outbound signed with retries)None exists; needed by payments, WhatsApp, aggregators
Credential vaultTable with envelope encryption; keys in app key/KMS laterGateway creds are plain JSON today (S2)
