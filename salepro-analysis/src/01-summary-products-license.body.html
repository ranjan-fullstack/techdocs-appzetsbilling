Straight answers

  • Can the pair technically run a commercial SaaS? Yes for a first few hundred tenants: it has separate-DB tenants, packages with limits, trials, 15+ gateways including Razorpay, a super-admin dashboard, CMS, affiliates and tickets [[V]]. Beyond ~1,000 tenants the database-per-tenant model and per-tenant "Update Client DB" workflow become operational problems that the add-on does not document solutions for [[INF]].
  • Is it a fit for restaurants? Partly. Floors/tables, waiter, dine-in/takeaway/delivery, KDS and QR menu are advertised [[V]]. Ingredient deduction on sale is not automatic in the docs excerpt ("production is manual, not automatic on sale") [[V]], no aggregator integration was found, and KOT printer routing, split/merge bill and captain app are undocumented [[UNK]]. Retail/wholesale/pharmacy-lite/electronics is where it is strongest.
  • Is the licence fee the risk? No: $245 is roughly ₹22,000 [[ASM]] (₹90/USD). The risk is engineering lock-in, the 72-sale add-on maturity, the unresolved licence interpretation, and duplicating a product you already have.
  • Recommendation [[REC]]: do not purchase yet. Run the 2–3 week due-diligence in Part 11 (author Q&A in writing, demo walk-through, licence confirmation), then decide between (a) extend AppZetBilling, (b) SalePro SaaS for a retail/wholesale vertical only, (c) both. Our current lean is (a) for restaurants, with SalePro considered only as a retail-vertical accelerator.

What Envato's terms say [[V]]

  • Regular: one single End Product "for yourself or for one client". "You can't Sell the End Product, except to one client." Free end products may be copied to any number of free users. (Regular terms, clauses 2, 5, 7; licence summary: "Use in an end product that's sold: No".)
  • Extended: one single End Product which "may be Sold"; "You can Sell and make any number of copies of the single End Product." It is "a 'single application' license and not a 'multi-use' license" — a second unique End Product needs another licence. (Extended terms.)
  • Prohibited under both: using the item in an application that lets end users customise a product ("on demand", "made to order", "build it yourself"). A POS is not that, but a white-label builder feature could drift into it [[INF]].
  • Search-result summaries of Envato's help article "Can I use Envato Market items in a SaaS product?" state that paid-access SaaS needs the Extended licence and that one Extended licence covers all customers of that single SaaS product ([[TP]] summary; the help page itself returned HTTP 403 to our fetcher, so we did not read it directly). 26. Questions we must ask the CodeCanyon author before buying

Put these in a written pre-sale ticket at the LionCoders support portal and keep the reply as evidence.

Licensing / legal

  1. Does one Extended licence of SalePro + one Extended licence of the SaaS add-on cover a hosted subscription service with unlimited tenants and unlimited paying customers, under one brand?
  2. Is a tenant DB copy treated as a separate "End Product" under any LionCoders policy?
  3. Is the PHP requirement 8.2+ or 8.3+, and which price is correct ($39 on CodeCanyon vs $69 on lion-coders.com)?
  4. If we run two brands (restaurant, retail) on the same codebase, is that one End Product or two?
  5. Will you provide a licence/invoice document naming our company for Indian audit and investor due diligence?
  6. After the 6/12-month support window, do we keep receiving updates and can we still download new versions?
  7. Are we allowed to modify source and remove LionCoders branding/credits in the tenant and super-admin UI?

Technical

  1. How does the add-on create tenant DBs on a plain VPS with no cPanel/Plesk? Does it use MySQL root credentials stored in .env? Can it target multiple DB servers (sharding)?
  2. What is the largest production SaaS deployment you know (tenant count, DB server size)?
  3. How are tenant updates applied at scale ("Update Client DB")? Is there a batch/queued migration runner, rollback, and failure reporting? Approx. time per tenant?
  4. Does the restaurant module (tables, KDS, QR menu, modifiers) work in SaaS tenants and can it be toggled per package? Is offline POS supported in tenants?
  5. How does offline POS sync work: what data is cached, how are conflicts and duplicate invoice numbers resolved, and what is the maximum offline duration?
  6. Is there a REST API (for tenants and for the super admin)? Is it documented? Is there a webhook system?
  7. How is Razorpay integrated in SaaS billing — one-time payments each renewal, or Razorpay Subscriptions/UPI AutoPay mandates? Are failed-payment retries and grace periods supported?
  8. Does tenant deletion drop the DB? Is there soft-delete/restore? How are backups per tenant scheduled ("Backup Client DB": manual or scheduled)?
  9. The Activity Log covers create/update/delete of sales, purchases and quotations. Does it cover logins, price changes and super-admin actions? Is there login history, IP/device tracking, 2FA? Is it per tenant in SaaS?
  10. Which stack parts are encrypted at rest (gateway credentials, API tokens)?
  11. The docs describe an "Indian GST" invoice format with CGST/SGST/IGST. Please share a sample invoice. Is e-invoicing (IRN) or e-way bill on the roadmap, and where is the consolidated India GST report?
  12. Is Odia supported as a language, and is a thermal-printer Odia glyph rendering supported (many ESC/POS printers cannot print Odia; image-mode printing needed)?
  13. What is the roadmap for the next 12 months, and how are breaking changes communicated to SaaS operators with customised code?
  14. Is the Restaurant module (floors, KDS, modifiers) a separate paid item? Which of Manufacturing, Repair, Tailoring, Social Commerce and Project are included in the $30 licence (the docs list Manufacturing and Repair as add-ons)?
  15. Do you offer paid customisation, what is your rate/turnaround, and will you accept a code-escrow/continuity agreement?
  16. Are there known scalability limits (per-tenant table count, session storage, queue usage)? Does the app need a queue worker and cron and which jobs run there?
  17. Can we see a real SaaS instance (staging login) with a package that enables restaurant + accounting + HRM?
